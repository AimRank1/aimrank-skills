# seo-clustering-lite: free AimRank teaser skill

Cluster keywords by **search intent** in Claude Code and turn the top gap into a brief. A free teaser of the method behind AimRank's SEO + Content Strategy blueprint.

*Methodology reference: [Ahrefs on keyword clustering](https://ahrefs.com/blog/keyword-clustering/), grouping keywords by search-result similarity. Referenced for method only; AimRank is not affiliated with Ahrefs.*

## Install (30 seconds)

```bash
git clone https://github.com/AimRank1/aimrank-skills.git
# personal (all projects)
cp -r aimrank-skills/seo-clustering-lite ~/.claude/skills/
# or project-local
cp -r aimrank-skills/seo-clustering-lite <your-repo>/.claude/skills/
```

Then in Claude Code: *"Cluster the keywords in ./keywords.csv by intent"*. The skill triggers automatically. No connectors, no API key, no account.

## What you get

- Intent-based clusters (not string-match) with funnel stage
- Content-gap detection against your sitemap
- A ready brief for the top opportunity

## What it does not do

This skill clusters the list you paste inside one conversation. It has no search-results, volume or ranking data, so intent is its reading and not a verified fact, and gap priority is a rough judgment. It tracks nothing over time.
