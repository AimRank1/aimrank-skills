# brand-content-lite: free AimRank teaser skill

Draft on-brand marketing copy in Claude Code with **a built-in claims check**. A free teaser of the method behind AimRank's Brand-Voice Content blueprint.

*Methodology reference: [Salesforce's Einstein Trust Layer](https://developer.salesforce.com/blogs/2023/10/inside-the-einstein-trust-layer), a generate-then-check layer around generative AI. Referenced for method only; AimRank is not affiliated with Salesforce.*

## Install (30 seconds)

```bash
git clone https://github.com/AimRank1/aimrank-skills.git
# personal (all projects)
cp -r aimrank-skills/brand-content-lite ~/.claude/skills/
# or project-local
cp -r aimrank-skills/brand-content-lite <your-repo>/.claude/skills/
```

Then in Claude Code: *"Draft an on-brand LinkedIn post from ./brief.md"*. The skill triggers automatically. No connectors, no API key, no account.

## What you get

- On-voice copy from your brand guide + brief
- A compliance self-check list flagging risky claims
- A check of whether an AI-content disclosure is needed

## What it does not do

This skill drafts and self-checks one piece at a time inside one conversation. It has not learned your voice from your approved content, its claims check is a reading and not a rule engine, it keeps no log of what was checked, and nothing it writes should be published without a person approving it.
