# call-analysis-lite: free AimRank teaser skill

Analyze a Lithuanian sales call in Claude Code: **talk ratio, objections, next steps, coaching, every insight quote-backed**. A free teaser of the method behind AimRank's Sales Call Analysis blueprint.

*Methodology reference: [Gong's conversation intelligence](https://www.gong.io/blog/elements-of-effective-sales-conversations/), built on more than 1 million analysed sales calls. Referenced for method only; AimRank is not affiliated with Gong.*

## Install (30 seconds)

```bash
git clone https://github.com/AimRank1/aimrank-skills.git
# personal (all projects)
cp -r aimrank-skills/call-analysis-lite ~/.claude/skills/
# or project-local
cp -r aimrank-skills/call-analysis-lite <your-repo>/.claude/skills/
```

Then in Claude Code: *"Analyze the call transcript in ./call.txt"*. The skill triggers automatically. No connectors, no API key, no account.

## What you get

- Talk ratio + an evidence table (insight · verbatim quote)
- Objections, next steps and missed questions extracted
- Coaching scores against a clear rubric

## What it does not do

This skill reads one transcript inside one conversation. It does not transcribe audio, has no benchmark built from your own winning calls, links nothing to a CRM, and keeps no consent record or history across calls.
