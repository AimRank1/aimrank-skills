# review-response-lite: free AimRank teaser skill

Turn an online review into an aspect-by-aspect read **plus a compliant draft reply** in Claude Code: one that never reveals a patient, over-claims, or gets defensive. A free teaser of the method behind AimRank's Reputation Guardian blueprint.

*Methodology reference: [Trustpilot's Trust Report 2025](https://corporate.trustpilot.com/trust/trust-report-2025). Referenced for method only; AimRank is not affiliated with Trustpilot.*

## Install (30 seconds)

```bash
git clone https://github.com/AimRank1/aimrank-skills.git
# personal (all projects)
cp -r aimrank-skills/review-response-lite ~/.claude/skills/
# or project-local
cp -r aimrank-skills/review-response-lite <your-repo>/.claude/skills/
```

Then in Claude Code: *"Draft a compliant reply to this Google review for our dental clinic: …"*. The skill triggers automatically. No connectors, no API key, no account.

## What you need

The review text + platform + star rating, your business type (flag healthcare/regulated), and any brand-tone note.

## What you get

- An aspect / sentiment breakdown (what actually drove the review)
- A warm, brief **draft reply** that passes a confidentiality + claims + tone gate
- A compliance note (checks passed, specifics deliberately kept private) and escalation flags

## What it does not do

Drafts, never posts: a person publishes. It monitors nothing and keeps no record. It won't gate (ask only happy customers for reviews), won't fabricate reviews, can't remove a negative review, and never confirms a patient or discloses care in public.
